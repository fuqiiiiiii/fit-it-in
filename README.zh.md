# fit-it-in

**在塞满的日历里，帮你把事情排进去。它推荐，你拍板。**

每天早上，Claude 读一遍你的日历（课、会议、健身），把今天画出来，空档标成 A、B、C。你说一句「论文周五交，大概 2 小时」，它推荐放在哪；你回一个字母。你不点头，什么都不会写进日历。

![fit-it-in 演示：早上的图、丢一个 deadline、三个候选窗口、回「A」、时间块出现](assets/demo.zh.gif)
<sub>示意动画，数据为虚构，格式与规则的真实输出一致。</sub>

自动排程工具替你做决定，这个只给建议。它不会擅自打乱你的一天，也永远不会记下你「没做完」什么。

**约 240 行大白话规则 · 没有一行 app 代码 · Claude + Google 日历 · 中文 & [English](README.md)**
作者本人从 2026 年 9 月 16 日起几乎每天早上都在用 · 排过 20 多个 deadline。

---

## 适合你吗？

- 搭过 Notion、滴答清单、手账，坚持不到一个月就放弃了
- 你的每一周都不太一样：课、轮班、会议
- 你的日程本来就在 Google 日历里，平时也用 Claude

## 安装（大约 5 分钟）

需要：一个 GitHub 账号、一个包含 Claude Code 和定时任务的 Claude 套餐、Google 日历（Gmail 可选，用来收邮件版）。

1. 点 **Use this template** → 建一个**私有**仓库。这个仓库就是你的 planner，你的设置都存在这里。
2. 在 Claude 里连接 **GitHub** 和 **Google 日历**，然后在新仓库上开一个 Claude Code 会话。
3. 随便说一句话，比如「你好」或者「我周五有个 essay 要交」，设置就会自动开始。

根目录的规则是英文的，但你用中文说话、它就用中文回复。想让规则文件本身也是中文，把 `zh/` 文件夹里的文件覆盖到根目录即可。

设置时它会先读你的日历，所以只问你一个问题（每天几点把安排发给你），再加一个可以跳过的问题（吃饭和通勤）。接着给你看一份今天的预览，然后帮你建好每天的定时任务。

## 丢一个 deadline 进去

```
你：     统计作业周五交，大概 2 小时
Claude： 统计作业 · 周五截止 · 需 3h12（估2h + 60% 余量）

         ★A 周三 13:00–16:30  在家  ███████ 3h30  一次做完
          B 周三 19:00–21:00  在家  ████    2h    要配 E
         ★C 周四 13:45–16:00  校内  ████    2h15  要配 E
          E 周五 08:00–09:15  在家  ██      1h15  只够收尾

         推荐 A：唯一能一次装下的窗口。不想周三太满就 C+E。
         挑哪个？回字母，多选写一起（"C E"）
你：     A
Claude： 已写进日历。不合适直接在 Google Calendar 里拖。
```

## 直接说话就行

| 你说 | 它做 |
|---|---|
| 「实验报告周一交，大概 2h」 | 给候选窗口，你选了才写日历 |
| 「essay 做完了」 | 删掉这个 deadline |
| 「essay 挪到周四」 | 重新给候选窗口 |
| 「我现在二四 7 点出门」 | 更新你的作息 |
| 「brief 改到 8 点」/「先停一下」 | 改时间，或暂停每天的 brief |

## 不适合你，如果……

- 你喜欢打卡、完成率、待办池。这里刻意一个都没有
- 你上夜班，或者凌晨以后才睡（暂不支持）
- 你经常跨时区（目前只支持一个时区）
- 你用 Outlook 或苹果日历（目前只支持 Google 日历）

## 常见问题

**为什么没有待办清单？** 清单上每一项没做完的事，都是一笔小欠账。欠账越积越多，清单就变成了你不想打开的东西。这里的 deadline 只是日历上的全天备注，每一天都重新排。

**为什么只排满 2/3 的空闲时间？** 剩下的是故意留白。把一天排满 100% 的计划，遇到第一件意外就会崩。周末只排 1/3。

**为什么我说 2 小时，它排了 3h12？** 事情通常比我们预想的多花 60% 左右的时间。不同意就说「不加系数」。

**我的数据存在哪？** 在你自己的私有仓库和你自己的 Google 账号里。没有服务器。

**规则能改吗？** 能。你的设置在 `config/` 里，用大白话说就能改。系统怎么运作写在 [`AGENTS.md`](AGENTS.md) 里，是普通的文字，你也可以自己改。
